# Rules for AI Coding Agents

Authoritative source of truth for this Flutter project. All directives apply to code reviews, architecture, and implementation.

## Mandatory Reading (EVERY command)
- ALWAYS read `.claude/lessons/` files alongside these rules before starting any task.
- **Before every commit, PR, or review:** run the **Pre-commit & Review Checklist** in `.claude/lessons/pre_commit_checklist.md`. If any check fails, **STOP and warn the user** — do not proceed silently.

**Canonical reference feature:** `lib/features/agents/` — study its cubit, model, service, view, widget, and constants folders before writing new features.
